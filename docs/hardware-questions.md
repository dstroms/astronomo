# Open hardware questions

These are the driver assumptions a finished night still has to answer on the Seestar S50 Pro connected on 2026-11-13 (firmware 9.75, Alpaca switched on in the app, computer on the telescope's Wi-Fi). That night passed the hardware check, slewed and saved 32 frames. It did not finish a mission. How to connect is in [Connect a real Seestar](connect-a-seestar.md) and in [Real hardware](real-hardware.md). The order for the night that fills the blank rows is in [the first-clean-night runbook](runbooks/first-clean-night.md). Why the JSON-RPC handshake is not implemented is in the [firmware note](notes/firmware-and-authentication.md).
